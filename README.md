# Estructura de Datos y Algoritmos

Repositorio de trabajos prácticos de la materia Estructura de Datos y Algoritmos, desarrollados en Java.

## Trabajos prácticos

- **Análisis de Algoritmos:** ejercicios de análisis y resolución de problemas.
- **Recursividad:** ejercicios y algoritmos recursivos.
- **Ordenamiento:** algoritmos de ordenamiento.
- **Listas Enlazadas Simples:** implementación y operaciones con listas enlazadas.
- **Pilas y Colas con Arreglos:** implementación de pilas y colas utilizando arreglos.
- **Pilas y Colas con Listas Enlazadas:** implementación de estructuras lineales con nodos.

## Tecnologías

- Java
- Git
- GitHub

## Organización

Cada trabajo práctico se encuentra en su propia carpeta e incluye los ejercicios y archivos correspondientes.
