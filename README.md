# Estructura de Datos y Algoritmos

Repositorio de trabajos prácticos de la materia Estructura de Datos y Algoritmos, desarrollados en Java.

## Trabajos Prácticos

- **1-AnalisisDeAlgoritmos**: Resolución de problemas fundamentales sobre vectores y matrices[cite: 8], enfocándose en el análisis de complejidad temporal y espacial ($O(n)$, $O(1)$), la distinción entre estructuras ordenadas y desordenadas (búsqueda lineal vs. binaria), y el conteo detallado de operaciones elementales.
- **2-Recursividad**: Implementación de funciones recursivas[cite: 9] en Java aplicando el paradigma de diseño basado en la identificación formal de casos base, casos recursivos, reducción de problemas y gestión de la pila de llamadas (métodos aplicados a factoriales, potencias, operaciones matemáticas sin operadores directos, manipulación de cadenas y vectores).
- **3-Ordenamiento**: Desarrollo y comparación empírica de algoritmos de ordenamiento internos[cite: 10] (Bubble Sort, Selection Sort, Insertion Sort, ShellSort, Quicksort y MergeSort), analizando métricas de rendimiento como cantidad de comparaciones, intercambios, saltos (*gaps*), comportamiento ante arreglos semi-ordenados y el paradigma de divide y vencerás.
- **4-PilasYColasConArreglos**: Construcción de estructuras de datos lineales estáticas[cite: 11] utilizando arreglos de tamaño fijo, implementando políticas LIFO (Pilas para gestión de historiales, validación de paréntesis y torres de platos) y FIFO (Colas lineales y circulares con manejo del operador módulo para optimizar el espacio de memoria).
- **5-ListasEnlazadasSimples**: Creación e implementación de listas enlazadas dinámicas desde cero, gestionando de forma manual nodos, referencias de memoria (*head*), recorridos secuenciales, inserciones y eliminaciones por valor o posición, manipulación de enlaces, inversión de estructuras y adaptación a tipos genéricos en Java.
- **6-PilasYColasConListasEnlazadas**: Reimplementación dinámica de pilas y colas mediante listas enlazadas simples y doblemente enlazadas, garantizando operaciones en tiempo constante $O(1)$ mediante el uso de punteros de control optimizados (`head` y `tail`), aplicadas a sistemas de atención de clientes, colas de impresión y estructuras genéricas reutilizables.
